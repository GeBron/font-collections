## 🛠️ 安装与使用建议

### 1. 本地安装
- **Windows**: 选中 `.ttf` 文件，右键点击 **“为所有用户安装”** 或 **“安装”**。
- **macOS**: 双击 `.ttf` 文件打开“字体册 (Font Book)”，点击 **“安装”**。
- **Linux**: 将字体文件复制到 `~/.local/share/fonts/` 或 `/usr/share/fonts/`，然后运行 `fc-cache -fv`。

### 2. VS Code 编程字体配置示例
在 `settings.json` 中配置：
```json
{
  // 推荐组合 1: Fira Code + 霞鹜文楷等宽
  "editor.fontFamily": "'Fira Code', 'LXGW WenKai Mono GB Screen', Consolas, monospace",
  "editor.fontLigatures": true,

  // 推荐组合 2: Maple Mono + 霞鹜文楷等宽
  // "editor.fontFamily": "'Maple Mono Normal', 'LXGW WenKai Mono GB Screen', monospace",
  // "editor.fontLigatures": true,

  // 推荐组合 3: Google Sans Code
  // "editor.fontFamily": "'Google Sans Code', 'LXGW WenKai Mono GB Screen', monospace",
  // "editor.fontLigatures": true
}
```

### 3. Web 网页引入 WOFF 示例
```css
@font-face {
  font-family: 'SongTi';
  src: url('./weread/思源宋体.woff') format('woff');
  font-weight: normal;
  font-style: normal;
}

body {
  font-family: 'SongTi', serif;
}
```
